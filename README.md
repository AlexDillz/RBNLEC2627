# ШВМ ОЛАС «Рубин» 2026-2027

Статический сайт с лекциями и материалами Школы вожатского мастерства ОЛАС «Рубин» на сезон 2026-2027.

Участник сканирует QR-код, попадает на главную со списком лекций и открывает нужную. Кроме лекций на сайте есть страницы «Команда и лекторы» и «Наши контакты».

Сайт сделан максимально простым в поддержке: обычные HTML, CSS и JavaScript, без сборщиков и без backend. Публикуется через GitHub Pages.

## Структура проекта

```text
.
├── index.html            главная: шапка, кнопки и список лекций (строится из lectures.json)
├── lectures.json         список лекций
├── contacts.html         страница «Наши контакты»
├── style.css             все стили сайта
├── theme.js              переключатель светлой и тёмной темы
├── protect-local.js      защита страниц лекций (локальный просмотр и закрытые лекции)
├── lectures/
│   ├── _template.html    шаблон страницы лекции (только для копирования)
│   └── personas.html     страница «Команда и лекторы»
└── assets/
    ├── personas/         фото команды
    └── lecs/<id>/        материалы конкретной лекции (создаётся по мере надобности)
```

## Как добавить лекцию

Пример ниже для лекции с id `vvod-lec`. Id придумываешь сам: латиница, цифры, дефис или подчёркивание, без пробелов. Он используется в имени файла, в `lectures.json` и в папке с материалами, везде одинаково.

1. **Скопируй шаблон.**
   Скопируй `lectures/_template.html` в `lectures/vvod-lec.html`.

2. **Заполни страницу.** В новом файле замени всё, что помечено комментарием `ЗАМЕНИ`:
   - `НАЗВАНИЕ ЛЕКЦИИ` в `<title>` и в `<h1>`;
   - пример контента внутри `<div class="content">` на текст лекции;
   - `LECTURE_ID` в последней строке на свой id:
     ```html
     <script src="../protect-local.js?v=7" data-lecture-id="vvod-lec"></script>
     ```
   Большой комментарий в начале файла можно удалить.

3. **Положи материалы.** Презентации, PDF и картинки клади в `assets/lecs/vvod-lec/`. Из страницы лекции на них ссылаются так:
   ```html
   <a class="btn btn-download" href="../assets/lecs/vvod-lec/slides.pdf" download>Скачать презентацию</a>
   <img src="../assets/lecs/vvod-lec/scheme.jpg" alt="Схема">
   ```

4. **Добавь запись в `lectures.json`.** Порядок в массиве = порядок карточек на главной.
   ```json
   {
     "lectures": [
       {
         "id": "vvod-lec",
         "title": "Вводная лекция. Роль вожатого в лагере",
         "summary": "Начало пути. Основы и ценности.",
         "url": "lectures/vvod-lec.html",
         "locked": true
       }
     ]
   }
   ```
   Следи за запятыми между записями: одна лишняя или пропущенная запятая ломает весь список.

5. **Открой или закрой лекцию флагом `locked`.**
   - `"locked": true`: на главной карточка с замком и кнопкой «Скоро», а по прямой ссылке вместо лекции показывается сообщение «Эта лекция пока закрыта».
   - `"locked": false`: карточка кликабельна, лекция открыта всем.

   Обычно лекцию заранее выкладывают с `true`, а в день лекции меняют на `false`.

6. **Если у лектора есть карточка** в `lectures/personas.html`, туда можно добавить кнопку на лекцию с параметром `from=personas`, тогда кнопка «Назад» в лекции вернёт на страницу команды:
   ```html
   <a class="person-lecture-btn" href="../lectures/vvod-lec.html?from=personas">Вводная лекция</a>
   ```

7. Закоммить изменения и отправь в `main`. GitHub Pages обновит сайт через минуту-две.

Пока массив `lectures` пустой, на главной показывается сообщение «Лекции скоро появятся».

## Локальный запуск

```bash
python3 -m http.server 8000
```

Затем открой http://localhost:8000.

Главная, контакты и «Команда и лекторы» работают как обычно. Страницы лекций локально показывают заглушку «Файл открыт локально»: так работает `protect-local.js`, это нормально. Для отладки можно временно поставить `DEV_MODE = true` в начале `protect-local.js`, но перед коммитом обязательно верни `false`.
