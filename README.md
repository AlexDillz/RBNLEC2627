# ШВМ ОЛАС «Рубин» 2026-2027

Сайт Школы вожатского мастерства ОЛАС «Рубин» на сезон 2026-2027.

Участник сканирует QR-код, попадает на главную страницу со списком лекций и открывает нужную. Кроме лекций на сайте есть страницы «Команда и лекторы» и «Наши контакты».

Сайт статический: обычные HTML, CSS и JavaScript, без сборщиков и без сервера. Публикуется через GitHub Pages, обновляется сам после каждого коммита в `main`.

## Структура проекта

- `index.html` - главная страница, список лекций строится из `lectures.json`
- `lectures.json` - список лекций
- `lectures/` - страницы лекций, по одному HTML-файлу на лекцию
- `lectures/personas.html` - страница «Команда и лекторы»
- `contacts.html` - страница «Наши контакты»
- `style.css` - все стили сайта
- `theme.js` - переключение светлой и темной темы
- `protect-local.js` - защита страниц лекций (локальный просмотр и закрытые лекции)
- `assets/personas/` - фото команды
- `assets/lecs/<id>/` - материалы лекции: презентации, PDF, картинки

## Как добавить лекцию

У каждой лекции есть id: латиница, цифры, дефис, без пробелов. Например `vvod-lec`. Этот id используется в имени файла, в `lectures.json` и в папке с материалами, везде одинаково.

### 1. Создать страницу лекции

Создай файл `lectures/<id>.html`, например `lectures/vvod-lec.html`, и вставь в него этот код:

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Название лекции</title>
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <link rel="stylesheet" href="../style.css">
  <script src="../theme.js" defer></script>
  <script>
    document.addEventListener('DOMContentLoaded', function () {
      const from = new URLSearchParams(window.location.search).get('from');
      if (from !== 'personas') return;
      document.querySelector('.close-card-btn').href = 'personas.html';
      const back = document.querySelector('.lecture-footer .btn');
      back.href = 'personas.html';
      back.textContent = '← Назад';
    });
  </script>
</head>

<body>
  <button id="theme-toggle" aria-label="Переключить тему">Темная тема</button>

  <article class="card lecture-card">
    <a class="close-card-btn" href="../index.html" aria-label="Назад к списку">
      <svg class="close-icon" viewBox="0 0 24 24" aria-hidden="true" focusable="false">
        <line x1="6" y1="6" x2="18" y2="18" />
        <line x1="18" y1="6" x2="6" y2="18" />
      </svg>
    </a>

    <div class="content">
      <h1>Название лекции</h1>

      <!-- здесь текст лекции -->

      <div class="lecture-footer">
        <a class="btn" href="../index.html">← Назад к лекциям</a>
      </div>
    </div>
  </article>

  <script src="../protect-local.js?v=7" data-lecture-id="vvod-lec"></script>
</body>
</html>
```

В этом коде нужно поменять три вещи:

- название лекции в `<title>` и в `<h1>`;
- `data-lecture-id="vvod-lec"` в последней строке на id своей лекции;
- комментарий `<!-- здесь текст лекции -->` на сам текст.

Все остальное не трогай.

### 2. Оформить текст

Текст пишется внутри `<div class="content">`, между `<h1>` и `<div class="lecture-footer">`. Основные теги:

| Что нужно | Как писать |
|---|---|
| Заголовок раздела | `<h2>Режим дня</h2>` |
| Подзаголовок | `<h3>Утро</h3>` |
| Абзац | `<p>Обычный текст.</p>` |
| Жирный | `<b>важно</b>` |
| Курсив | `<i>термин</i>` |
| Перенос строки внутри абзаца | `<br>` |
| Маркированный список | `<ul><li>пункт</li><li>пункт</li></ul>` |
| Нумерованный список | `<ol><li>шаг</li><li>шаг</li></ol>` |
| Ссылка на сайт | `<a href="https://example.com" target="_blank">текст</a>` |

Пример:

```html
<h2>Режим дня</h2>
<p>Режим дня - <b>основа</b> жизни отряда. Подробнее про <i>режимные моменты</i> ниже.</p>

<h3>Что входит в утро</h3>
<ol>
  <li>Подъем</li>
  <li>Зарядка</li>
  <li>Завтрак</li>
</ol>
```

Каждый открытый тег нужно закрыть: `<p>` и `</p>`, `<b>` и `</b>`, `<li>` и `</li>`. Если забыть, верстка поедет.

### 3. Прикрепить файлы и картинки

1. Создай папку `assets/lecs/<id>/`, например `assets/lecs/vvod-lec/`.
2. Положи туда файлы. Имена лучше писать латиницей и без пробелов: `slides.pdf`, `scheme.jpg`.
3. Вставь в текст лекции ссылку или картинку.

Кнопка скачивания файла:

```html
<a class="btn btn-download" href="../assets/lecs/vvod-lec/slides.pdf" download>Скачать презентацию</a>
```

Картинка:

```html
<img src="../assets/lecs/vvod-lec/scheme.jpg" alt="Схема режима дня">
```

Путь всегда начинается с `../assets/lecs/`, потому что страница лекции лежит в папке `lectures/`.

### 4. Добавить лекцию в список

Открой `lectures.json` и добавь запись в массив `lectures`:

```json
{
  "lectures": [
    {
      "id": "vvod-lec",
      "title": "Вводная лекция. Роль вожатого в лагере",
      "summary": "Начало пути. Основы и ценности.",
      "url": "lectures/vvod-lec.html",
      "locked": true
    }
  ]
}
```

- `id` - тот же, что в `data-lecture-id` на странице лекции;
- `title` - название на карточке;
- `summary` - короткое описание под названием;
- `url` - путь к странице лекции;
- `locked` - закрыта лекция или открыта (см. ниже).

Порядок записей в массиве равен порядку карточек на главной. Между записями ставится запятая, после последней записи запятой нет. Одна лишняя или пропущенная запятая ломает весь список.

### 5. Открыть или закрыть лекцию

- `"locked": true` - на главной карточка с замком и кнопкой «Скоро», а по прямой ссылке вместо лекции показывается сообщение «Эта лекция пока закрыта».
- `"locked": false` - лекция открыта всем.

Удобно заранее выложить лекцию с `true`, а в день лекции поменять на `false`.

### 6. Кнопка на странице лектора (по желанию)

Если у лектора есть карточка в `lectures/personas.html`, туда можно добавить кнопку на его лекцию:

```html
<a class="person-lecture-btn" href="../lectures/vvod-lec.html?from=personas">Вводная лекция</a>
```

Тогда кнопка «Назад» в лекции вернет на страницу команды, а не на главную.

### 7. Опубликовать

Закоммить изменения в `main`. Через минуту-две GitHub Pages обновит сайт.

Пока в `lectures.json` нет ни одной лекции, на главной показывается сообщение «Лекции скоро появятся».

## Локальный запуск

```bash
python3 -m http.server 8000
```

Затем открой http://localhost:8000.

Главная, контакты и «Команда и лекторы» работают как обычно. Страницы лекций локально показывают заглушку «Файл открыт локально», это нормально: так работает `protect-local.js`. Для проверки лекции можно временно поставить `DEV_MODE = true` в начале `protect-local.js`, но перед коммитом обязательно верни `false`.
